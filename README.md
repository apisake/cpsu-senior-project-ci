# CPSU senior PROJECT: ชุดไฟล์ CI (Corporate Identity) 2026

โฟลเดอร์นี้รวมไฟล์ทั้งหมดที่ต้องใช้กับอัตลักษณ์ของ CPSU senior PROJECT ทั้งไฟล์นำเสนอ CI โลโก้ทุกรูปแบบ สี และกราฟิกประกอบ หยิบไปใช้ต่อได้ทันที

## โครงสร้างโฟลเดอร์

```
CPSU Senior Project CI/
├── README.md                              ← ไฟล์นี้

│   ├── CPSU-Senior-Project-CI-Guidelines.pdf    ← ไฟล์นำเสนอ CI (14 หน้า, 16:9)
│   ├── CPSU-Senior-Project-CI-Guidelines.html   ← ฉบับเปิดในเบราว์เซอร์
│   ├── Slides PNG/                               ← ภาพสไลด์ทีละหน้า 1920×1080
│   └── assets/                                   ← ภาพประกอบของไฟล์ HTML
├── 02 Logo/                               ← โลโก้ 6 รูปแบบ ทั้ง .png และ .svg
└── 03 Brand Assets/
    ├── CPSU-SP-Colors.css                 ← รหัสสี ไล่เฉด และฟอนต์
    ├── CPSU-SP-Sparkle.svg                ← ประกายดาว
    └── CPSU-SP-Speed-Bars.svg             ← เส้นความเร็ว
```

## ไฟล์นำเสนอ

- **PDF**: ใช้เปิดนำเสนอหรือส่งต่อ เปิดได้ทุกเครื่อง
- **HTML**: ดับเบิลคลิกเปิดในเบราว์เซอร์ ต้องอยู่ในโฟลเดอร์นี้ เพราะใช้ภาพจาก `02 Logo` (ฟอนต์โหลดจาก Google Fonts จึงต้องต่ออินเทอร์เน็ต)
- **Slides PNG**: ภาพสไลด์ทีละหน้า ลากไปวางใน PowerPoint หรือ Keynote ได้
- **ฉบับออนไลน์ที่แก้ไขได้**: https://claude.ai/artifact/ANwqusQAFdzHfnsaTWHjUb
  ดาวน์โหลดเป็น PPTX ได้จากเมนู Export ในหน้านั้น (ลิงก์นี้เปิดได้เฉพาะคนที่เจ้าของแชร์ให้)

## โลโก้ (02 Logo)

| ไฟล์ | ใช้เมื่อ | ขนาด PNG |
|---|---|---|
| CPSU-SP-Logo-Primary | พื้นเขียว รูปโปรไฟล์ สติกเกอร์ | 1080 × 1080 |
| CPSU-SP-Logo-Mark-Light | วางบนพื้นขาว สไลด์ เอกสาร | 1080 × 1080 โปร่งใส |
| CPSU-SP-Logo-Mark-Dark | วางบนพื้นเข้มหรือพื้นเขียว | 1080 × 1080 โปร่งใส |
| CPSU-SP-Logo-Mono | พิมพ์สีเดียว ปั๊ม สกรีน | 1080 × 1080 โปร่งใส |
| CPSU-SP-Logo-Horizontal | หัวสไลด์ แบนเนอร์ ป้าย | 2000 × 854 โปร่งใส |
| CPSU-SP-Logo-Icon | ไอคอนเล็ก รูปโปรไฟล์ LINE | 1080 × 1080 |

- **PNG** ใช้กับงานทั่วไป
- **SVG** ใช้เมื่อต้องขยายใหญ่ เช่น ป้ายไวนิล ตัวอักษรในไฟล์แปลงเป็นเส้นแล้ว เปิดได้ทุกเครื่องโดยไม่ต้องลงฟอนต์
- Mark-Dark มีส่วนสีขาว ถ้าเปิดดูบนพื้นขาวจะเห็นไม่ครบ ซึ่งเป็นปกติ ให้วางบนพื้นเข้มหรือพื้นเขียว

## ฟอนต์ (ฟรีจาก Google Fonts รองรับภาษาไทย)

- **Kanit** ExtraBold Italic: หัวเรื่อง ข้อความเด่น https://fonts.google.com/specimen/Kanit
- **Anuphan**: เนื้อหา คำอธิบาย ตาราง https://fonts.google.com/specimen/Anuphan
- **Avenir Next**: ใช้ในโลโก้เท่านั้น ห้ามพิมพ์คำว่า CPSU senior PROJECT ขึ้นใหม่ ให้ใช้ไฟล์โลโก้เสมอ

## ข้อห้ามสำคัญ

1. ห้ามยืดหรือบีบโลโก้ ให้ย่อขยายโดยล็อกสัดส่วนเสมอ
2. ห้ามใช้สีนอกพาเลตข้างบน
3. ห้ามสลับลำดับคำ ต้องอ่านว่า CPSU senior PROJECT เสมอ
4. ห้ามเน้นตัวใดตัวหนึ่งใน CPSU
5. ห้ามเพิ่มเงาหรือเอฟเฟกต์ให้โลโก้
6. ห้ามวางโลโก้บนภาพที่รก ถ้าจำเป็นให้รองด้วยพื้นทึบสีเข้มก่อน

ระยะปลอดภัย: เว้นรอบโลโก้อย่างน้อย X ทุกด้าน โดย X คือความสูงของแถบ PROJECT
